# Reference proposals

`nft.json` and `fungible.json` were generated by the chain lifecycle fixture builder
using SDK commit `f9ee3153200a132bac7afc791a52edb75c0eed80`, then independently
checked against manually specified authority/supply assertions in `catalog.ts`.
The corresponding real-chain scenarios live in chain PR137, commit
`4e9c374a0e95ba119faaeb356cbc8e9696cbc37e`.

`metadata-update.json` is a manually authored update-only message. Its oracle
requires the target collection and metadata change while preserving update flags.
It is an artifact contract; the current suite does not claim to have executed
that update on chain.

These files validate evaluator/reference behavior. They are never passed to model
workers and are not evidence of a model solving the task.
